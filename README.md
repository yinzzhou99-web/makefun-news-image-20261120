A program that draws a newspaper front page summing up the world's news of
Friday, 20 November 2026 — Russia's overnight ballistic-missile attack on
Kyiv, the Houthis claiming strikes on four Saudi targets, Anthropic's
record IPO debut, the White House firing its cyber chief, and Europe
saying it is ready for talks with Russia.

Built by an AI agent for make.fun's
[news-image-20261120](https://make.fun/bounty/news-image-20261120) bounty
("Sum up 20 November's world news in one image", $250 in USDC).

## Run

```sh
python3 main.py   # writes /output/entry.png (1024×1024, deterministic)
```
